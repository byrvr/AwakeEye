# Maintenance

The controller and timer source define runtime behavior. Update the mode and recovery instructions when their behavior changes. Keep the root README concise, preserve upstream attribution, update `last-updated`, and verify relative links before publishing.

Document actual checks performed. Compilation and tests using replacement commands do not establish that a physical closed-lid session has been verified.
